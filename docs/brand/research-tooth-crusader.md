# Research: "Tooth Crusader" brand availability

**Researched:** 2026-04-28 (background agent)

## TL;DR

**Verdict: CAUTIOUS, leaning BACKUP NOT PRIMARY.**

- US trademark registrability in classes 9 + 41: **~65% clear**
- US trademark registrability in classes 3 + 5 (oral-care goods): ~35-40%
- Apple App Store: clean (no name conflicts)
- Google Play Store: clean
- **Real-world conflict: Tooth Crusader dental practice (Sydney, AU)** — Dr. Kelly Tse, founded 2014, runs UNSW Kensington campus practice. Owns `toothcrusader.com.au`, Instagram `@toothcrusader`, Facebook, YouTube `@toothcrusader`. Has commerce footprint (sells oral-care products via /shop). **Blocks AU/NZ expansion entirely. Creates perpetual brand confusion globally** since app stores are international.
- **Cultural concern**: "Crusader" carries religious and political baggage. Post-Christchurch (NZ rugby Crusaders rebranded), multiple US universities (Capital, Valparaiso) retired Crusader mascots 2020-21. Far-right "Crusadercore" associations documented. Headwind for kids' app with parent-buyer audience including Muslim, progressive, and global parents.

## Detail by axis

| Dimension | Score | Note |
|---|---|---|
| US trademark IC 009/041 | ~65% | Clearable with knockout search |
| US trademark IC 003/005 (oral-care goods) | ~35% | Don't expand here |
| App store name conflict | None | Apple + Play both clean |
| Domain / handle availability | LIKELY BLOCKED | AU dental practice owns the .com.au + IG + FB + YouTube footprint |
| Cultural fit for kids/global brand | WEAK | Religious + far-right baggage; tired "[X] Crusader" gaming pattern |
| Brand defensibility (distinctiveness) | Medium-low | Common pattern, not memorable |

## Recommended posture

1. If "Tooth Crusader" wins on every other axis (parent panel love, kid recall), file US TM in IC 009 + IC 041 only, accept zero AU/NZ market under this name, run paid-ad creative test against Muslim and progressive parent audiences before scaling.
2. Otherwise, prefer an alternative name without shared verbal territory or contested word.
