## Implications for our trademark strategy

The original W-1 plan assumed BRUSH QUEST would face only Mitchell's potential challenge. That changes:

|---|---|---|
| Mitchell challenge | Real but defensible | Confirmed: he has no trademark filing, only weak common-law rights |

## Three viable paths now

### Path 1 — File "BRUSH QUEST" word mark anyway, accept ~50% Office Action risk
- File USPTO TEAS Plus, $500 (2 classes)
- If Office Action issued: respond with distinctness arguments (~$0 if DIY response, ~6-12 months added timeline)
- If Workman opposes: that's where DIY gets real hard. Opposition costs $400+ to USPTO, plus need legal arguments. Likely settle or withdraw.

### Path 2 — File a stylized/design mark instead of word mark
- File the BRUSH QUEST logo + wordmark combination (not the word alone)
- Stylized marks are inherently more distinct → much lower confusion risk
- Protection is narrower (only protects that specific design), but still a defensive moat
- Same $500 filing cost, ~80% lower Office Action risk
- Trade-off: someone could use "BRUSH QUEST" as plain text legally

### Path 3 — Rebrand to a name that's clearly distinct
- Avoid the "[noun] QUEST" pattern entirely
- Candidates to brainstorm: "Tooth Crusader," "Brush Squad," "Cavity Hunters," "Brushtopia," etc.
- Costs 2-3 weeks of asset rework (icon, listing, screenshots, promo video, copy)
- Eliminates BOTH conflicts (Mitchell's app + BRAIN QUEST similarity)
